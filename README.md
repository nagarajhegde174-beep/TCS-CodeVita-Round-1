# TCS CodeVita Round 1 Solutions

This repository contains my solutions to 6 TCS CodeVita (Round 1) programming problems, implemented in Java.

## Problems

- **Problem A** – ASCII Census (`ASCII_Census.java`)
- **Problem B** – Memory Fragmentation (`Memory_Fragmentation.java`)
- **Problem C** – Rainy Campus (`Rainy_Campus.java`)
- **Problem D** – Robot Route (`Robot_Route.java`)
- **Problem E** – Smart Cut (`Smart_Cut.java`)
- **Problem F** – Snake Game (`Snake_Game.java`)

## Language

Java

## Purpose

To practice problem-solving, algorithms, and computational thinking for coding contests.
